# The Symbol Grounding Framework (SGF)

The **Symbol Grounding Framework (SGF)** is an architecture for transforming language and data into grounded, source-traceable, frame-aware claims. It allows machine meaning to be governed, audited, and moved safely across systems and trust boundaries.

Instead of traditional storage methods, SGF processes clauses into **Synapses**: hub-and-spoke event packets centered on a verb with up to 15 fixed roles (agent, patient, time, place, instrument, reason, etc.). These are backed by a **Core Lexicon** of sense-level Canonical IDs, proof traces, and explicit gaps.

Utilizing the **"Third Protocol" (HFF/AFP)** and the **Omega** governance language, these grounded claims travel between machines as admissible meaning plus typed acts. This enables zero-prior-integration coordination, conflict-aware knowledge graphs, and AI systems capable of auditing their own actions, knowledge, and justification.
